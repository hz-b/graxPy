# Create Custom Grating Profiles

You can define your own grating geometry by subclassing
`grax.gratings.BaseGrating`.

A custom profile must implement:

- `profile_points()`: one period as `(x_positions_nm, heights_nm)`
- `profile_depth_nm()`: geometric depth in nanometers

## Sinusoidal profile example

```python
import numpy as np
import grax as rp
from grax.gratings import BaseGrating


class SinusoidalGrating(BaseGrating):
    def __init__(self, *, depth_nm: float = 20.0, samples_per_period: int = 1024, **kwargs):
        super().__init__(**kwargs)
        self.depth_nm = float(depth_nm)
        self.samples_per_period = int(samples_per_period)

    def profile_points(self) -> tuple[np.ndarray, np.ndarray]:
        x = np.linspace(0.0, self.period_nm, self.samples_per_period + 1)
        heights = 0.5 * self.depth_nm * (1.0 + np.sin(2.0 * np.pi * x / self.period_nm))
        return x, heights

    def profile_depth_nm(self) -> float:
        return self.depth_nm
```

## File-pattern example

Any measured or generated profile file can be used. For instance, if you have measured profile data from AFM, load and normalize one period:

```python
import numpy as np

afm_data = np.loadtxt("afm_profile_one_period.csv", delimiter=",")
x_raw = afm_data[:, 0]
z_raw = afm_data[:, 1]

# Normalize to [0, period] and [0, depth]
x = (x_raw - x_raw.min()) / (x_raw.max() - x_raw.min()) * period_nm
heights = z_raw - z_raw.min()
depth_nm = float(heights.max())
```

Then return `x` and `heights` from `profile_points()` and return `depth_nm` from
`profile_depth_nm()`.

## Inherited visualization and export

Custom classes inheriting `BaseGrating` can still use the standard methods:

- `plot_profile(...)`
- `save_structure_debug_data(...)`
- `build_textures(...)` (through normal simulation execution)

So you can keep the same plotting and simulation workflow used by built-in
laminar and blazed gratings.
