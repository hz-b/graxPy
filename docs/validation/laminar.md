# Laminar Grating (400 l/mm, fixed angle)

This comparison uses the laminar fixed-angle workflow from `validation/laminar`.

## Grating design parameters

- Grating type: `LaminarGrating`
- Period: `400 l/mm`
- Duty cycle (`width_to_period_ratio`): `0.67`
- Groove depth: `14.9 nm`
- Left wall angle: `15.0 deg`
- Right wall angle: `15.0 deg`
- Substrate material: `Si`
- Coating material: `Pt`
- Coating thickness: `28.77 nm`
- Top cap material: `C`
- Top cap thickness: `0.7 nm`
