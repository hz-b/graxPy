# Blazed Grating

This comparison uses the blazed-grating workflow from `validation/blazed`.

All simulation curves use the same optical constants, and measured data is shown for comparison.

## Grating design parameters

- Grating type: `BlazedGrating`
- Period: `600 l/mm`
- Blaze angle: `0.729 deg`
- Anti-blaze angle: `5.597 deg`
- Substrate material: `Si`
- Coating material: `Au`
- Coating thickness: `30.0 nm`
- Top cap: `None`
