Workflow 01

Gratings

Make an etched profile, save it, and run a scan from its detail page.

New grating

1. Define the grating

Open Gratings → New grating. Enter a name, choose the profile type, and set its period and shape. Choose a bare substrate or a coating stack, then set materials and any density overrides. The Live preview lets you check the profile before you select Save grating.

Use Gratings → Manage gratings to reopen or edit a saved definition. Choose None as a coating material when you want an uncoated case in a material variation.

2. Set up a run

Open the saved grating. In Run sweep, choose the workflow that matches your question: Energy sweep at a fixed grazing angle, Angle sweep at one energy, Monochromator at fixed CFF, or Constant deviation (2θ). The page shows the fields for the selected workflow.

Set diffraction order, polarization, numerical resolution, and solver in the shared settings. Add independent or coupled variations when comparing several parameter combinations. Check the count before choosing Run sweep.

3. Find and use the results

Follow the run's progress and live plot. Later, open Gratings → Manage grating runs to find saved runs, inspect their settings, or download full result tables. For a comparison of selected curves, use Plots → New plot; that plot has its own Edit and Download actions.
