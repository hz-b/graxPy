How the website is organized

  1. Choose a workspace. The home page shows the active data folder. Use Choose folder… there to work in another local folder. Saved models, runs, and plots belong to that folder.
  2. Create and save a model. Start from the Gratings, Plane mirrors, or Multilayer grating menu. Saving a grating or mirror gives you a page where you can set up a run.
  3. Run and review. A run page shows progress and results. Use the matching Manage runs page to find it again.
  4. Compare and download. Open Plots → New plot to combine saved runs. On a saved plot, Edit plot changes its settings, and Download offers PNG, plotted CSV data, or data with a Python plotting script.

Useful input conventions

Angles are labelled in degrees and lengths in the units shown beside each field. Choose S (TE) or P (TM) polarization in the run settings. Decimal fields follow your dot or comma preference; arrow buttons and a focused field's mouse wheel change values by the field's step.
