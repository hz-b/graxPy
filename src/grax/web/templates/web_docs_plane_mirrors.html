Workflow 02

Plane mirrors

Save a flat layer stack first, then configure and run its reflectivity scan.

New plane mirror

1. Build the layer stack

Open Plane mirrors → New plane mirror. Give the mirror a name and choose the stack type: bare substrate, single layer, custom layers, or periodic multilayer. Enter materials, thicknesses, and roughness where the form asks for them. Check the Layer stack preview beside the form, then choose Create mirror.

Find the stack later under Plane mirrors → Manage plane mirrors. Use Edit mirror on its page to change the saved stack.

2. Choose a reflectivity scan

On the saved mirror page, choose Energy sweep, Angle sweep, or Monochromator under Run sweep. Enter the scan range and polarization. The Reflectivity preview responds to your settings before you select Start run.

Use Save current scan settings as a preset when you expect to repeat a setup. Independent ranges and coupled values let you compare layer or scan parameters in one run.

3. Review the run

Use Plane mirrors → Manage plane-mirror runs to reopen saved results. In Plots → New plot, choose a mirror run to compare its reflectivity with other saved runs. The saved plot's Download menu offers its image and the x/y values of the displayed curves.
